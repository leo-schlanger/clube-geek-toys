# Fotos de eventos (loja)

Pasta servida em `shop.geeketoys.com.br/eventos/<slug>/...`

1. Coloque JPGs/WebP em `public/eventos/<slug>/` (mesmo `slug` de `src/data/event.ts`)
2. Liste em `ACTIVE_EVENT.photos` em `src/data/event.ts`
3. Deploy

Manter alinhado com o site institucional (`geek-toys-home/public/eventos/`).

Ver `docs/EVENTS.md`.
